# Projects

### LockIn — HackNC 2026 Community Track Winner

Note-taking app for live lectures: students upload the slide deck, take notes page by page, and get on-demand AI help — a catch-up summary, a worked example, an explanation — without ever being interrupted. Those same requests are logged anonymously and aggregated into a lecturer dashboard showing where in a lecture students got lost and why.

Built in 23 hours with a team of four, out of 119 projects submitted. I owned the PDF/slides module (DPI-aware canvas rendering, per-page text extraction, a domain-term extractor that primes both AI prompts and speech-to-text against technical vocabulary) and the Postgres aggregation layer, where student anonymity is enforced in SQL rather than in the UI.

**Technologies:** React, Node.js/Express, PostgreSQL, pdf.js, Gemini API, ElevenLabs

### Senior Capstone — Production Web Application

Year-long capstone building proprietary software for an industry client, currently running in beta. I lead Scrum for a team of five and work across the stack: a NestJS REST API with a Prisma data layer, a React frontend, OAuth via Amazon Cognito, and Playwright end-to-end tests gated by a GitHub Actions pipeline on AWS.

**Technologies:** TypeScript, NestJS, React, Prisma, AWS (S3, Lambda), Docker, Playwright

### Streetlight Monitoring & Automation Platform

Full-stack web platform for monitoring and automating **722 streetlights across 56 LoRaWAN-controlled circuits** in a Wilmington residential community. Built as an undergraduate research assistant at UNCW, with requirements gathered directly from the community association.

I designed the architecture and REST API, modeled a Prisma schema that separates physical fixtures from switchable circuits, and imported 722 geolocated lights from a KMZ survey. Device monitoring is event-driven — controllers report in rather than being polled — which keeps the system inside platform API rate limits as it scales.

**Technologies:** React, TypeScript, Node.js/Express, PostgreSQL, Prisma, LoRaWAN

---

### Distributed WiFi Monitoring System

Four Raspberry Pis in monitor mode capturing WiFi probe traffic via `tcpdump`, parsing MAC addresses, RSSI, and timestamps to approximate device location across a grid and drive an occupancy heatmap. I led a four-person team through Agile Scrum and built the sensor layer, including automated startup routines, adaptive logging, and multi-device synchronization for long-duration operation.

**Technologies:** Python, Linux, tcpdump, Raspberry Pi, networking
